# Trademark and Protocol Attribution

## LocalSend protocol

"LocalSend" is an open peer-to-peer file-sharing protocol developed and
maintained by the **LocalSend organization** (<https://localsend.org/>). The
protocol specification is published under an MIT license at
<https://github.com/localsend/protocol>.

This repository acknowledges and thanks the LocalSend organization for
publishing the protocol openly so that interoperable, independent
implementations are possible.

## Vianium LocalSend

**Vianium LocalSend** is an **independent, compatible implementation** of the
LocalSend protocol for Windows Phone 8.1. It is not a fork or derivative of the
LocalSend reference application; it is a clean-room WinRT/C# implementation
that speaks the LocalSend wire protocol so that Windows Phone 8.1 devices can
interoperate with desktop and mobile LocalSend clients on the local network.

Vianium LocalSend is **not affiliated with, endorsed by, or sponsored by** the
LocalSend organization, its maintainers, or its contributors. Any reference to
"LocalSend" in this repository is descriptive — it identifies the protocol
that Vianium LocalSend implements and the ecosystem of clients it is
interoperable with. No endorsement or partnership is claimed or implied.
